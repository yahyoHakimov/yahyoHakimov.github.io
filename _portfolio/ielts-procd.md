An online platform for computer-based IELTS preparation built with **C#**, **.NET**, **PostgreSQL**, and **Vue.js**.

**Key features:**
- Secure test administration with timed sessions
- Real-time progress tracking and score analytics
- RESTful API backend integrated with HTML/CSS/Bootstrap frontend

**Infrastructure:** Backend deployed on AWS EC2 with Docker; frontend served via Nginx.
