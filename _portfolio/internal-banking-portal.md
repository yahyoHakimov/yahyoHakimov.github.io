Developed an internal banking portal for **Universalbank JSCB** to streamline operational workflows.

**Key features:**
- JWT authentication and role-based access control (RBAC)
- Employee, meeting, attendance, and department management modules
- RESTful API with SQL Server backend

**Stack:** C# · .NET · Vue.js · SQL Server · AWS EC2

Reduced unauthorized access incidents by 35% after implementing RBAC and audit logging.
